# ADR-0009：合并按批准时冻结的值分发

- **状态**：Accepted
- **日期**：2026-11-21
- **确认依据**：用户批准按登记时冻结的值执行，并要求修正代码。
- **替代范围**：[ADR-0005](0005-merge-execution-model.md) 决策 2 及 2026-11-15 补充中关于执行期复核的部分、R08 的取源最新值规则，以及 R09 对登记后目标并发修改的规定。条目归属、双侧证据、轮次结果与确认所有权继续适用。

登记时校验并保存双侧证据和决定。分发时依据已登记决定及冻结值，按目标 Tracker 分类发布可靠事件。业务 BC 监听支持的分类，在独立事务中校验目标身份、期望锁及业务不变量，并发布结果。来源在登记后编辑或升版仍允许按冻结值执行。已有业务目标在登记后发生并发修改时返回冲突。

比较过的另一方案是由目标 BC 执行时重新复核双侧证据。它可拦截来源后续变化，但保留同步回读依赖，并在用户已批准的值仍可提供时要求重新审阅。[方案权衡与验收场景](../reviews/2026-11-21-merge-dispatch-bc-boundary.md)

已有轮次沿用持久化的双侧证据。后续实施裁定采用空库重建开发和 Demo 数据，批准事件要求明确的目标分类。部署到保留数据的环境时，旧格式事件须在切换前排空。
