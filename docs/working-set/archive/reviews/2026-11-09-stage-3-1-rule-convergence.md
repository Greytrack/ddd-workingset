## 原待裁定事项（现均已裁定，保留选项作为评审记录）

1. **候选清单批准范围**：批准 R01—R17 及上述限定术语作为首版内容，或指出需暂缓的具体行；影响是知识状态和后续基线纳入资格，不选择聚合，不自动发布。
2. **QUESTION-004 / POL-005，同一家族在一个工作集能否同时有多个有效变体？** 选项：只允许一个；或允许多个并要求显式选择
   Tracker/变体。前者允许 CommonId 在工作集内唯一解析，后者要求解析与合并携带消歧信息。全局家族唯一并不能回答此问题。
3. **QUESTION-006，派生内容保证覆盖哪些从属数据？** 选项：附件和关系也固定为派生时状态；或按业务类别划定固定/动态范围，但首次编辑所需数据必须可用。影响是
   Source Cut 覆盖和删除守卫；保留存储方式由后续技术设计处理，不再询问来源删除后子需求是否可编辑。

治理；它们不阻塞本清单的限定规则整理，本轮不扩大裁定。并发、幂等、结果未知、Checkpoint 乱序、GateFlow
切换及共享读取面验收属于后续协议设计，不作为用户重复裁定问题。聚合 QUESTION-001/002/012 保持候选，未推进。
