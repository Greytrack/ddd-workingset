沿用 INV-014 的父节点有效范围要求，创建时必须确定合法父或 null 根；不另造重复“父有效”编号。INV-015 的无环检查集中于创建候选结构，不再将“创建后并发移动”作为合法用例。具体无环算法、创建批次原子性与可见性未批准。
