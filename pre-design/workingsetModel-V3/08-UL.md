# Shared Kernel 工作集 — 统一语言词汇表

> 当前 V4 术语见 [工作集统一语言](./workingsetModel/10-ubiquitous-language.md)，整体类图见 [领域模型](./workingsetModel/01-domain-model.md)。本文作为历史术语资料。

> 本页保留旧版 UL；V4 工作集本体的术语与边界以 [领域模型](./workingsetModel/01-domain-model.md) 为准。代理属于实现词汇，不替代 LightTrackerItem 的领域含义。

> **文档版本**: v2.21
> **最后更新**: 2026-10-27

本上下文描述共享实例身份、工作集对 Tracker 的选择与派生，以及条目的独立演化与合并。业务 BC 直接依赖稳定共享模型，存储来源和 COW 状态由 SK 内部管理。

## Language

**WorkingSet（工作集）**：
项目内具名的工作上下文，通过 Tracker 绑定选择使用的数据版本线。它具有自己的生命周期，不作为业务条目的整体事务容器。
_Avoid_: 工作集分支、Tracker 的别名

**Tracker**：
业务对象容器、结构定义和数据版本线；既可为原始 Tracker，也可通过 SourceTrackerId 成为派生 Tracker。
_Avoid_: TrackerBranch、独立 BranchId

**TrackerSharingMode（Tracker 共享策略）**：
Tracker 创建后不可变的属性；SHARED 使多个工作集复用同一 Tracker，UNSHARED 使派生工作集使用独立 Tracker。
_Avoid_: BindingMode、可变共享状态

**SourceTrackerId（来源 Tracker 标识）**：
Tracker 的直接派生来源标识，为空表示原始 Tracker。
_Avoid_: ParentTrackerId、内容来源指针

**ParentTrackerId（父 Tracker 标识）**：
Tracker 在业务分类或结构层级中的父级标识。
_Avoid_: 派生来源

**DerivedTracker（派生 Tracker）**：
SourceTrackerId 非空的 Tracker；isDerived 由此事实计算。
_Avoid_: 可独立修改的 derived 标记

**WorkingSetTrackerBinding（Tracker 绑定）**：
WorkingSet 对 Tracker 的选择关系，是工作集内的实体；共享策略来自 Tracker。
_Avoid_: 带独立共享策略的成员关系

**TrackerSnapshot（Tracker 快照）**：
一个来源 Tracker 在 capturedAt 时刻可见的条目集合及有效内容的确定切点，用于派生。
_Avoid_: 动态最新内容、异步 Job 的执行时刻

**HEAD（即时快照）**：
用户选择当前时刻创建派生体系的命令语义；权威时间由服务端受理请求时捕获。
_Avoid_: 持续移动的最新版本

**InstanceIdentity（实例身份）**：
所有 BusinessObject 共有的 CommonId 与 LocalId 身份，不包含 TrackerId 或 WorkingSetId。
_Avoid_: 仅限工作集的身份

**CommonId（通用标识）**：
同一实例血缘中保持不变的根身份；它全局唯一且永不复用。
_Avoid_: 当前具体实例主键

**LocalId（本地标识）**：
一个具体实例全局唯一、不可变的身份；原生实例与 CommonId 相等，派生实例与 CommonId 不同。
_Avoid_: TrackerId、仅在物理行生成后存在的标识

**TrackerItem（Tracker 条目契约）**：
Shared Kernel 对外统一的业务对象能力，表达实例身份、Tracker 归属、条目类型与只读实例化事实；受管业务类型直接实现它。
_Avoid_: 业务对象必须继承的骨架类、物理行存在性的保证

**TrackerItemInstantiator（条目实例化协调能力）**：
SK 提供的跨条目实例化能力，统一准备目标及其派生子树的独立本地内容，直接返回请求目标业务对象。
_Avoid_: BC 类型复制 SPI、实体实例方法、仅当前条目复制

**IsInstantiated（已实例化事实）**：
TrackerItem 加载时对本地物理内容存在性的只读观察，权威状态由 SK 内部管理。
_Avoid_: 可修改的业务状态、直接写入许可、永不过时的事实

**TrackerItemContentPort（条目内容访问端口）**：
具体 BC 提供完整业务内容读取、重建、物理复制、保存与清理的访问契约，不承担闭包决策。
_Avoid_: 公开实例化协调器、跨聚合流程

**LightTrackerItem（轻量 Tracker 条目）**：
Tracker 下一个条目的持久化轻量表示，管理身份、内容来源与状态；未实例化和已实例化条目都保留该表示。它不实现 TrackerItem，不等同于运行时代理。
_Avoid_: 仅代表未实例化对象、对外完整业务对象、TrackerItemShadow 的同义词

**TrackerItem 代理（实现词汇）**：
由加载入口按需组装的运行时适配对象，实现 TrackerItem 以隐藏内容来源解析；不单独持久化，不承载派生链路事务。具体业务类型可直接通过类型化加载重建，无需通用代理。详见 [V4 §5.1](./workingsetModel/01-domain-model.md#light-record-and-proxy)。
具体实现命名为 LightTrackerItemProxy；TrackerItemProxy 仅指代理角色，不建立第二层同名类。RequirementQueryModel 在查询侧调用 RequirementFactory 重建目标身份业务对象；命令侧重新加载并执行写保护。详见 [V4 简例](./workingsetModel/04-query-command-demo.md)。
_Avoid_: 新领域聚合、LightTrackerItem 的别名、实现接口即可自动启用 COW

**TrackerItemLocator（条目上下文定位器）**：
WorkingSetId 与 CommonId 组成的公开用例输入，经 Binding 定位当前 Tracker 中的条目。
_Avoid_: 物理主键、轻量条目的固有身份

**SourceLocalId（内容来源实例标识）**：
LightTrackerItem 当前内容来源的实例标识；实例化后指向自身 LocalId。
_Avoid_: 血缘父指针

**SourceRevision（来源版次）**：
来源实例的确定版次；非版次控制实例固定为 1，并不以此宣称当前可变行具有历史版本。
_Avoid_: 动态最新版、内容并发版本

**InstantiationState（实例化状态）**：
SK 内部对本地物理内容存在性的判断：VIRTUAL 尚无本地物理内容，INSTANTIATED 已有本地物理内容。
_Avoid_: 对外业务状态

**InstantiationClosure（实例化闭包）**：
待变更实例及同一 CommonId 下位于其 Tracker 派生子树中的后代实例集合。
_Avoid_: 仅当前实例

**Instantiation（实例化）**：
为已分配身份的条目生成独立本地物理内容，校正归属并将内容来源重置为自身。
_Avoid_: 分配第二个 LocalId、查询时组装内存对象

**Resolution（条目解析）**：
在工作集上下文中取得完整业务对象，其身份属于目标条目、内容来自确定来源或本地实例。
_Avoid_: 查询时自动生成物理行

**Delete（软删除）**：
BusinessObject 从未删除态进入回收站的生命周期操作；受 Tracker 管理时，由 SK 自动准备实例化闭包。
_Avoid_: 物理删除

**Undelete（恢复）**：
BusinessObject 从回收站恢复为未删除态，保留原身份。
_Avoid_: 重新创建

**Delete2（彻底删除）**：
从回收站清除一个具体 LocalId 的实体、索引、版次及其拥有或作为物理端点的关系；成功后不可恢复。
_Avoid_: 按 CommonId 误删整个派生族

**Copy-on-Write（写时复制）**：
非共享派生时预建身份与内容来源；业务修改持久化前，由 SK 生成所需的独立本地内容。
_Avoid_: 业务调用方判断存储状态
