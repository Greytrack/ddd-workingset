# 统一语言

继承父规格的 WorkingSet、Tracker、Binding、TrackerItem、LightTrackerItem、CommonId / LocalId。

## 关系与方向

| 名词 | 定义 |
|---|---|
| Reference（引用） | 独立聚合根，表达某个引用属性指向的对象，可钉住目标版次 |
| Association（关联） | 独立聚合根，表达对象间业务联系，含类型、可选规则与传播怀疑能力 |
| 引用方 / 被引用对象 | 分别对应 sourceId / targetId；端点关联不代表聚合包含 |
| 上游引用 / 上游关联 | 我引用了谁 / 我关联了谁 |
| 下游引用 / 下游关联 | 谁引用了我 / 谁关联了我 |
| 悬空引用 | 已落库且有效的 Reference，左侧存在、右侧物理定位为空，目标逻辑依据仍保留 |

方向的保留与丢弃规则见 [02 §5](./02-domain-design.md#5-创建与扩展决策)。

## 版次、传播与派生

| 名词 | 定义 |
|---|---|
| RelationRevisionRecord | 引用聚合内的值对象，记录引用方某版次的行标记，每引用每版次最多一条 |
| RowMark | UNCHANGED / ADDED / INVALIDATED 三态 |
| 所钉目标版次 | 固定指向的目标版次；为空时跟随选定目标上下文的最新内容，与引用方版次不同 |
| 引用修复 | 拓展或合并事件提交后，补齐已有有效引用的右侧，不改变其身份 |
| AssociationRule | 关联内的可选值对象，整体设置或移除，名称按关联方视角渲染 |
| PropagationSuspect | 关系各自持有的传播怀疑能力，记录两端变化带来的待确认事实 |
| 关系派生 | 依据工作集索引与冻结来源建立新关系，不引入关系血缘 |
| 关系来源切点 | 固定关系集合与有效版次的历史依据，不是关系的血缘属性 |
| 有效关系视图 | 按引用方版次筛选关系，再按工作集上下文解析端点的查询结果 |

VIRTUAL 描述 Item 内容状态，不表示引用行尚未落库。
