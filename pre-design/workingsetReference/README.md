# 工作集引用与关联设计

> 定位：新版本领域设计与 DDD 实现依据。状态：待评审、未实施。

**Reference、Association 均为独立聚合根。** 创建工作集先建索引，再保存关系行；Item 内容采用 COW。

| 关系 | 创建工作集 | 拓展 / 合并后 |
|---|---|---|
| 上游引用 | 保留；右侧缺失也保存有效引用行 | 提交后通过事件修复同一引用 |
| 下游引用 | 不复制 | 不自动补建 |
| 上游关联 | 两侧齐全时建行，缺端点保留恢复意图 | 拓展按保留意图建立合法缺失关联 |
| 下游关联 | 丢弃，悬空关联不落库 | 永久丢弃，不恢复 |

丢弃限于新工作集的派生范围，不删除来源工作集或外部对象的原关系。
